# Triage labels

The engineering skills speak in five triage roles. This repo uses the default label
strings. Type and area labels (`type:*`, `area:*`) are defined in `CONTRIBUTING.md`.

| Role | Label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | The owner needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent |
| `ready-for-human` | `ready-for-human` | Needs the owner (accounts, billing, keys, approvals) |
| `wontfix` | `wontfix` | Will not be actioned |
