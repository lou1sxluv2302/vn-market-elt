# ADR-0009: Accept a process running for the whole session

- Status: Accepted
- Date: 2026-10-06
- Spec: D9

## Context

Streaming requires a process alive from 08:55 to 15:05 on trading days.

## Decision

Accepted by the owner (2026-10-06).

## Consequences

Monitoring and alerting are part of the definition of done for the collector.
