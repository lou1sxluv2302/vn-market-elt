# ADR-0014: English everywhere in this repository

- Status: Accepted
- Date: 2026-10-06
- Spec: D14

## Context

The repository is a public portfolio piece. The research repo is in Vietnamese.

## Decision

Identifiers, comments, commits, branches, tags and docs are in English. Conversation with the owner stays in Vietnamese.

## Consequences

Vietnamese market terms need a single translation table (ADR-0015).
