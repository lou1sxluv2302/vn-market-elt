# ADR-0016: GitHub Flow, Conventional Commits and SemVer

- Status: Accepted
- Date: 2026-10-06
- Spec: D16

## Context

A solo project gains nothing from GitFlow's second long-lived branch, but its history should still read like a team's.

## Decision

One protected `main`, short-lived typed branches, squash-merged PRs, Conventional Commits, one SemVer tag per phase.

## Consequences

Details live in `CONTRIBUTING.md`.
